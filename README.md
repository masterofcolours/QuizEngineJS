# QuizEngine.js

A lightweight, robust, and zero-dependency JavaScript library designed to create flexible and customizable quizzes and online examinations in the browser.

## Features

- Zero External Dependencies: Built entirely with vanilla JavaScript.
- Multiple Navigation Modes: Supports Lockstep mode (mandatory answering before advancing) and No-Backtracking mode.
- Built-in Timer: Configurable countdown timer with automatic quiz completion upon timeout.
- Unbiased Shuffling: Uses the Fisher-Yates (Knuth) algorithm to shuffle questions uniformly.
- Flexible Rendering: Decoupled logic and presentation, allowing complete control over styling and UI structure.
- Dual Package Distribution: Supports both ES Modules (ESM) and CommonJS (CJS) environments.
